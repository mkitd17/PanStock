# PanStock — Sistema de Control de Stock para Panadería

## Descripción del Problema
Una pequeña panadería requiere reemplazar el control manual de inventario por una solución automatizada. El sistema permite conocer los productos disponibles, el stock actual, registrar el historial de ingresos/egresos y generar alertas automáticas cuando el stock esté por debajo del mínimo establecido.
